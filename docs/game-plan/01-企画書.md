# 企画書(第2版)(仮題)分身AIが暮らす世界

## 一言でいうと
自分の性格を丁寧に診断して生まれた「分身AI」が、もうひとつの世界で自律的に暮らし、仕事や趣味や人付き合いを楽しむ、見守り型ライフゲーム。

## コンセプト
「自分に似た誰かが、もうひとつの世界で生きている」

## 決定事項
- 恋愛要素は入れない(分身の暮らしは、仕事・趣味・友人・探索が中心)
- 優先順位
  1. **最優先:性格診断と、分身の「自分らしさ」**
  2. **次点:世界の探索と暮らし**
  3. 後回し(最初は最小限):他のプレイヤーとの交流
- 性格診断は5軸×5段階 = 3,125タイプ

## 遊びの流れ
1. 性格診断(詳細な質問)に答える
2. 診断結果に合わせて分身AIが誕生する
3. 分身が世界に入り、自動で生活を始める
4. 分身の暮らし(日記・出来事)を見守る
5. プレイヤーが声をかけたり教えたりして、分身が学習・成長する

## 面白さの柱
- 診断の納得感:「これ、自分だ」と思える結果と分身
- 世界の多様さ:大自然、大都会、ファンタジーなど。性格によって似合う場所や暮らしが変わる
- 予測できない暮らし:分身が勝手に出かけ、選び、出会い、成長する

## ターゲット(仮)
性格診断が好きな人、育成・放置ゲームが好きな人、世界観の探索が好きな人

## 未決定の課題
- プレイヤーが分身にどこまで介入できるか
- 他のプレイヤーとの交流をどこまで入れるか(安全対策を含む)
- AIの運用費をどう賄うか
- 作る人(自作 / 外注 / 協力者)

# 性格診断の設計書(第2版)

## 前提
- 心理学の**ビッグファイブ(Big Five)**をもとにします。
- 質問票は、無料で商用利用できる**IPIP(国際性格項目プール)**をもとにする方針(案A)。
- 5軸×5段階 = **3,125タイプ**。

## 5軸
| 軸 | 左 ←→ 右 | ビッグファイブでの名前 | 分身の行動への影響 |
|---|---|---|---|
| 1. 社交性 | 内向 ←→ 外向 | 外向性 | 出かける場所、人と会う頻度 |
| 2. 思いやり | 自分優先 ←→ 相手優先 | 協調性 | 友人との接し方、助け合い、もめごとの対応 |
| 3. 計画性 | 気まま ←→ きちょうめん | 誠実性 | 生活リズム、仕事、お金の使い方 |
| 4. 心の安定 | 繊細 ←→ どっしり | 神経質傾向(逆向き) | 感情の波、落ち込みやすさ、立ち直り |
| 5. 好奇心 | 慣れた物が好き ←→ 新しい物が好き | 開放性 | 住む場所、新しいことへの挑戦 |

各軸は5段階です(例:1=かなり内向、3=中間、5=かなり外向)。

## 質問の作り方(案)
- 1軸あたり12〜16問、合計60〜80問(所要10〜15分)
- 各問は「まったく当てはまらない〜とても当てはまる」の5段階
- 軸ごとに点数を合計し、5段階に変換
- 診断の最後に「分身のプロフィール」を表示
- 3,125タイプを1つずつ作らず、5軸の点数から分身の行動を自動で決める方式(推奨)

## 世界との相性(次点の要素)
- 例:社交性が高い+好奇心が高い → 大都会、冒険の世界
- 例:社交性が低い+心が安定 → 静かな大自然
- 診断結果から「おすすめの世界」を提案し、プレイヤーが選べる

## 法律・権利のメモ(専門家の確認が必要)
- IPIPの英語原典はパブリックドメインで、商用利用できる。日本語訳は別の権利がある可能性があり、訳した人・団体の利用条件の確認、または自分で翻訳し直す
- BFI、NEO-PI-R、MBTIは商用の制限や有料のため避ける
- 診断結果は個人情報になりうるため、利用目的の明示と同意取得が必要
- 「診断」は医療・心理検査ではなく、楽しむための性格タイプ判定と明記する
- 公開前に、弁護士などへ1回相談する
