# 企画書(第1版)(仮題)分身AIが暮らす世界

## 一言でいうと
自分の性格を丁寧に診断して生まれた「分身AI」が、もうひとつの世界で自律的に暮らし、恋をして、他のプレイヤーの分身と交流する、見守り型ライフゲーム。

## コンセプト
「自分に似た誰かが、もうひとつの世界で生きている」

## 優先順位(決定済み)
1. **最優先:性格診断と、分身の「自分らしさ」**
   診断の納得感と、分身が本当に自分っぽく振る舞うこと。
2. **次点:世界の探索と暮らし**
   大自然、大都会、ファンタジーなど、多様な世界で分身が生活する楽しさ。
3. 後回し(最初は最小限):他のプレイヤーとの交流、恋愛ストーリーの作り込み

## 遊びの流れ
1. 性格診断(詳細な質問)に答える
2. 診断結果に合わせて分身AIが誕生する(4軸×5段階 = 625タイプ)
3. 分身が世界に入り、自動で生活を始める
4. 分身の暮らし(日記・出来事)を見守る
5. プレイヤーが声をかけたり教えたりして、分身が学習・成長する

## 面白さの柱
- 診断の納得感:「これ、自分だ」と思える結果と分身
- 世界の多様さ:性格によって、似合う場所や暮らしが変わる
- 予測できない物語:分身が勝手に出会い、選び、恋をする

## ターゲット(仮)
性格診断が好きな人、育成・放置ゲームが好きな人、恋愛ものが好きな人

## 未決定の課題
- プレイヤーが分身にどこまで介入できるか
- 恋愛表現の範囲(年齢制限、安全対策)
- 他のプレイヤーとの交流の安全性
- AIの運用費をどう賄うか
- 作る人(自作 / 外注 / 協力者)

# 性格診断の設計書(たたき台)

## 前提
- 「ビッグファイル」は、心理学の**ビッグファイブ(Big Five)**のことだと推測しています(違っていたら教えてください)。
- ビッグファイブは5つの特性(外向性、協調性、誠実性、神経質傾向、開放性)です。
- 5段階×4軸 = 625タイプにするため、**5つの特性から4軸にまとめる案**を出します。

## 4軸の案(恋愛と暮らしに効くもの)
| 軸 | 左 ←→ 右 | 分身の行動への影響 |
|---|---|---|
| 1. 社交性 | 内向 ←→ 外向 | 出かける場所、人との出会いの頻度 |
| 2. 感受性 | 論理的 ←→ 感情的 | 会話の仕方、恋愛での判断 |
| 3. 冒険心 | 慎重・安定 ←→ 好奇心・冒険 | 住む場所、新しいことへの挑戦 |
| 4. 距離感 | 自立・マイペース ←→ 寄り添い・密着 | 恋愛スタイル、友人関係 |

各軸は5段階です(例:1=かなり内向、3=中間、5=かなり外向)。

## 質問の作り方(案)
- 1軸あたり15〜20問、合計60〜80問
- 各問は「まったく当てはまらない〜とても当てはまる」の5段階で答える
- 軸ごとに点数を合計し、5段階に変換する
- 診断結果の最後に「分身のプロフィール」を表示する

## 世界との相性(次点の要素)
- 例:外向+冒険心が高い → 大都会、冒険の世界
- 例:内向+慎重 → 静かな大自然
- 診断結果から「おすすめの世界」を提案し、プレイヤーが選べる

## 次に決めること
1. 4軸の名前と中身(上の案でよいか)
2. 質問数(何分で終わらせたいか)
3. 診断の科学的な正確さをどこまで求めるか
